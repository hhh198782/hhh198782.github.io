登录以管理内容

用一枚 GitHub 个人访问令牌登录，即可在线增删改查「开源项目」与「技术记录」。改动会直接提交回你的仓库，对所有访客生效。

令牌只保存在你当前的浏览器里，仅用于直接与 GitHub 通信，不会发送到任何第三方服务器。

如何获取访问令牌？（一次性，约 1 分钟）
  1. 打开 细粒度令牌创建页（Settings → Developer settings → Fine-grained tokens → Generate new token）。
  2. 名称随意，Expiration 选一个有效期（如 90 天）。
  3. Repository access 选 Only select repositories，勾选 。
  4. Repository permissions 里把 Contents 设为 Read and write。
  5. 点 Generate token，复制以 github_pat_ 开头的令牌，粘贴到上面。
